# EimeSteine

Website for the holiday house *Ich saz uf eime steine* in Bellwald.

The site is plain HTML, CSS and JavaScript: no framework, no build step and no
runtime dependencies. Open `index.html` directly, or serve the folder with any
static file server.

## Photos

The photos in `galerij/fotos/` are the originals. The site loads responsive
WebP/JPEG variants from `galerij/opt/`, generated by:

```sh
python3 tools/build-images.py          # add missing sizes
python3 tools/build-images.py --force  # rebuild everything
```

The script needs Python 3 and ImageMagick 7 (`magick`). It also refreshes
`galerij/opt/manifest.json` and `galerij/opt/gallery-fragment.html`. To add a
photo, add an entry to `PHOTOS` in `tools/build-images.py`, run it, and paste the
new figure from the generated fragment into `fotos.html`.
